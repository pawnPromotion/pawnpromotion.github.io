第一阶段的目标不是把网站做得复杂，而是让它先成为一个可以持续写作、整理项目和展示个人主页的空间。

这次博客重建选择了 Hexo 和 Fluid。Hexo 负责把 Markdown 文章生成静态站点，Fluid 提供相对成熟的博客主题、归档、分类、标签、关于页、搜索和代码块样式。

## 为什么适合个人博客

个人博客的核心是长期维护。相比从零写页面，Hexo 的文章目录、frontmatter、主题配置和部署流程都比较清晰。

我希望这个站点同时承载三类内容：

- 技术笔记：记录工程实践、踩坑和学习总结。
- 生活随笔：保留一些非技术观察。
- 作品集：整理做过的项目、工具和实验。

## 第一阶段保留的边界

这一版先完成首页、文章列表、文章详情、分类、标签、关于页、作品集页和 GitHub Pages 自动部署。

评论、访问统计、RSS、站内搜索增强和自定义域名可以放到后续阶段逐步补上。

## 写作约定

图片统一放在 `source/img/` 目录下，文章中使用绝对路径引用：

```md
![图片说明](/img/example.jpg)
```

这样本地预览和 GitHub Pages 部署后的路径都会比较稳定。
